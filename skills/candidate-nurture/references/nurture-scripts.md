# 保温话术库

> 按"场景 × 阶段 × 升级等级"分场景的话术模板。话术不是死板模板，而是方向参考——实际发送时根据候选人情况微调语气和细节。

## 话术升级规则（与 _nurture_state.py 的 escalation_level 联动）

`escalation_level` 由 `nurture_state.py` 自动管理，基于触达次数和候选人回复状态：

| escalation_level | 触发条件 | 话术选择 | 场景参考 |
|---|---|---|---|
| **L1 轻量** | 首次触达，或候选人上次回复了（重置） | 用"轻催"段的话术 | 场景1的1-2天、场景2的3-5天、场景3的2-3天 |
| **L2 正常** | 上次 no_reply + 这是第 2 次触达（累计≥2）→ 自动升级 | 用"正常催"段的话术 | 场景1的3-4天、场景2的5-7天、场景3的4-5天 |
| **L3 强催** | 上次 no_reply + 这是第 3 次触达（累计≥3）→ 自动升级 | 用"强催"段的话术 | 场景1的5天+、场景2的7天+ |
| **⚠️ 建议终止** | L3 且仍 no_reply → status 变 escalated | **先问用户"这个还要不要继续跟"** | 不自动发话术，等用户决策 |

**升级是自动的，降级也是自动的**：
- 候选人回复了（`--response TID --status replied`）→ 重置到 L1
- 用户又碰了 escalated 的候选人 → 降回 L2，status 恢复 active
- 用户决定终止（`--reset TID`）→ status 变 terminated，不再出现在清单里

**怎么查当前等级**：
```bash
python "C:/Users/wuchunbo/.agents/skills/candidate-nurture/scripts/nurture_state.py" --read
```
输出里的 `L2:正常` / `L3:强催` 就是当前 escalation_level。

## 总原则

1. **催面评**（对面试官）：礼貌+明确+给压力点（候选人在等）。不要催得太凶，但要让面试官知道"这事拖不得"。
2. **碰候选人**（对候选人）：**给具体进展/预期，不要空问候**。"在吗？""最近怎样？"是废问候；"二面反馈在汇总，预计X号给答复"才是有效保温。
3. **长期停滞**：先判断"还要不要这个候选人"——如果业务已经不积极，提示用户考虑终止，别浪费保温成本。
4. **升级不等于凶**：L2/L3 话术的核心变化不是"更凶"，而是"更具体地给压力点"（如"候选人问了好几次"、"我怕压不住了"），同时给面试官台阶（"语音说两句我帮你记录也行"）。

## 场景1：催面评（对面试官）

### 面试后 1-2 天（轻催）
```
X总，{候选人名}的{轮次}面试（{日期}）方便写下面评吗？候选人在等结果，我这边好推进下一步～
```

### 面试后 3-4 天（正常催）
```
X总，{候选人名}一面过去{N}天了，候选人那边一直在等结果，担心拖久了他有其他选择。
方便今天抽空写下评价吗？如果太忙，语音说两句我帮你记录也行～
```

### 面试后 5 天+（强催）
```
X总，{候选人名}的{轮次}面评还没提交，已经{N}天了。候选人那边我有点压不住了，他问了好几次。
这个候选人之前评价不错，怕拖久流失。能否尽快？或者您觉得有什么顾虑直接说，我判断要不要继续推进。
```

**催面评的判断逻辑**：
- 面评全文现在可取（`interview_records/attachments` 接口）。催之前可以先查一下——如果面试官其实写了但没点"提交"，能拿到内容就不算"没写"
- 如果连续催 2 次面试官都不交，提示用户"这个面试官可能对面评流程不配合，建议找他的leader沟通"

## 场景2：停滞在"等约面"（对候选人）

### 停滞 3-5 天
```
{候选人名}你好，关于{岗位名}岗位，这边还在协调面试官的时间，预计本周内会安排面试。
你那边最近一周哪几天比较方便？我先记下来协调的时候优先匹配～
```

### 停滞 5-7 天
```
{候选人名}你好，关于{岗位名}的面试安排，面试官最近出差/项目忙，时间还没敲定，预计下周初能定下来。
你那边看机会的节奏有变化吗？如果还在看，我这边抓紧推进～
```

### 停滞 7 天+
```
{候选人名}你好，之前聊的{岗位名}岗位还在推进中，不过面试官时间协调得比较久，抱歉让你等了。
想确认一下你目前的求职状态——还在看机会吗？如果有其他offer在手上也告诉我，我帮忙协调加急～
```

## 场景3：面试后等结果（对候选人）— 保温节奏引擎核心场景

> **第一性原理**：候选人最在意的是"有人记得我"。很多候选人要的不是结果，而是知道 HR 没消失。面试后按节奏主动同步，哪怕没有任何进展也要发——价值在于"存在感"。

### D0 当天（面试刚结束）
```
{候选人名}你好，今天辛苦啦，也感谢你抽时间参与沟通～
业务这边后续会结合整体情况进一步评估，我这边有结果会尽快同步你。
```

### 面试后 2-3 天（无进展也要主动发）
> 这句话价值非常大。候选人看到的是：HR没消失。
```
{候选人名}你好，和您同步一下，目前还在内部推进中，暂时还没有最终结果。
我这边也一直在持续跟进，有消息第一时间联系您～
```

### 面试后 3-5 天（继续主动，哪怕只有一句）
```
{候选人名}你好，这边和您同步一下，我今天又跟进了一下流程，目前还在推进中，
我会继续关注，有消息第一时间告诉您🙏
```

### 面试后 4-5 天（面试官交了面评但还在走流程）
```
{候选人名}你好，{轮次}面已经有初步反馈了，整体评价不错，这边在走内部流程确认下一步。
预计{日期}前给你明确答复，保持联系～
```

### 拖一周以上（必须给信息量，不能只说"还在流程中"）
> ⚠️ 千万不要一直重复"还在流程中"。多一点信息量，候选人知道为什么慢，焦虑会少很多。只同步事实，不解读原因。
```
{候选人名}你好，不好意思让您久等了～我今天也跟进了一下，目前流程还在推进中，
业务这边还需要一点时间完成内部评估和确认，暂时还没有最终结果。
我会继续帮您关注进展，有新的消息第一时间同步给您，感谢您的耐心等待🙏
```

或（如确认卡在审批环节）：
```
目前主要是在内部审批环节，所以耗时会比面试阶段稍长一些，我这边会持续帮您关注。
```

## 场景4：面评通过，推进下一轮（对候选人·好消息）

```
{候选人名}你好，好消息🎉 {轮次}面通过了！
这边在安排下一轮（{下一轮类型}），预计{时间范围}，具体时间我协调好通知你。
你那边最近有什么不方便的时间段吗？我先避开～
```

## 场景5：面评不通过（对候选人·坏消息）

> ⚠️ 不通过消息**必须先跟用户确认措辞**，不能自动发。以下只是参考。

```
{候选人名}你好，关于{岗位名}的面试结果同步一下——经过综合评估，目前可能不是最合适的时机。
感谢你花时间参与面试，{可选：某个具体的正面反馈}。
如果以后有合适的岗位，我们再联系，祝你求职顺利～
```

## 场景6：Offer 阶段保温（候选人已拿offer，等入职）

```
1、入职材料（身份证/学历/银行卡）都准备好了吗？
2、入职当天上午9点到{地点}，联系人{HR姓名}

```

### 入职前 D-3
```
{候选人名}你好，入职倒计时3天📅 万事俱备了吗？
提醒一下带齐材料，周三上午见～
```

### 入职前 D-1
```
{候选人名}你好，明天就入职啦！明天上午9点{地点}见，{HR姓名}会接待你。
今晚好好休息，明天见～
```

## 场景7：节日/关键节点问候（批量保温）

> 适用于在管道里的候选人，节日主动问候 = 存在感。

```
{候选人名}你好，{节日}快乐🎉 
{岗位名}岗位这边还在推进中，节后给你同步进展。
假期愉快～
```

**节点清单**（自动保温的触发节日）：
- 春节、国庆、五一、中秋、端午（法定假）
- 圣诞、元旦（海外候选人更在意）
- 不建议：双11、情人节（太生活化，不像招聘方该发的）

## 话术使用的注意事项

1. **不要群发感**：话术里的 `{候选人名}` `{岗位名}` 必须替换成真实信息，让对方感觉是"单独给我发的"
2. **给具体预期**：避免"尽快""近期"这种模糊词，尽量给具体日期（"预计7-4前"）
3. **Emoji 适度**：技术岗少用（1个以内），运营/设计岗可以多用。不要每条都带🎉
4. **渠道选择**：飞书IM为主，电话用于"重要节点"（offer/不通过/长期停滞的紧急沟通）
5. **发送时机**：工作日 10:00-11:30、14:00-17:00 最佳。避免周一早（开会）和周五晚（下班）
